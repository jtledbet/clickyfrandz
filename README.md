# Clicky Friends

A click-memory game built with React.

## How to Play

Five animal friends are displayed in a random order. Click each one **exactly once**. After every click the board reshuffles, so you can't just go left-to-right — you have to remember which friends you've already visited.

- Click a new friend → score goes up, board reshuffles
- Click the same friend twice → **you lose**, board resets
- Click all five without a duplicate → **you win!**

## Project Structure

```
src/          ← edit this. these are the actual source files.
  App.jsx       the game component (state, click logic, render)
  App.css       styles
  index.css     base/body styles
  main.jsx      entry point (just mounts the app, don't touch)
  assets/       the five animal images

docs/         ← don't edit this. auto-generated by the build step.
              GitHub Pages serves the live site from here.
```

## Making Changes

```bash
npm install        # first time only
npm run dev        # starts a local preview at localhost:5173/clickyfrandz/
                   # changes to src/ show up instantly in the browser
npm run build      # compiles src/ → docs/ (run this before committing)
```

**The build tool is Vite** — it reads `src/`, bundles everything, and writes the
browser-ready output to `docs/`. You configure it in `vite.config.js` (already set up,
no need to touch it unless you're changing the base URL or output folder).

## Deployment

The live site is at `jtledbet.github.io/clickyfrandz`, served by GitHub Pages from
the `docs/` folder on the `master` branch.

To deploy a change:
1. Edit files in `src/`
2. Run `npm run build`
3. Commit both your source changes and the updated `docs/`
4. Push to `master`
